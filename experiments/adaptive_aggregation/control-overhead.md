# 控制判断局部优化记录

2026-10-28，Apple M4 Pro / darwin arm64。仅运行 Go 单元测试与控制器微基准，没有启动区块链实验。测试条件：24 分片、1000 条历史回执、每条包含 23 个目标分片统计，固定执行 1000 次；这是局部压力样本，不等同于百万笔集群负载。

| 操作 | 优化前 ns/op | 优化后 ns/op | 优化前 B/op | 优化后 B/op | 分配次数 前→后 |
|---|---:|---:|---:|---:|---|
| 稳定、无变化判断 | 28411 | 56.21 | 49733 | 0 | 4→0 |
| 冷却期间判断 | 27903 | 41.21 | 49536 | 0 | 3→0 |
| 收到回执并判断 | 44830 | 799.2 | 78855 | 1708 | 10→6 |

复现命令：

```bash
go test ./pkg/aggregation/routing -run '^$' \
  -bench BenchmarkRoutingEvaluation24Shards -benchtime=1000x -count=1
```

改动：

- Observe 收到有效且未重复的回执后增量更新各目标计数；样本过期时只减去该样本，避免每次判断扫描整个 10 秒窗口。
- 使用队列游标和低频原地压缩，释放过期统计引用，不复制整段活跃历史。
- 无策略变化时不分配计数数组、不复制策略；只在真正切换或到达原有重播时间时产生完整快照。
- 三窗恢复统计采用固定环形缓存及运行总和；不改变完整窗口、严格超过 75%、低水位或冷却规则。
- 保留源统计所有权与发布策略快照隔离，调用者修改入参或后续统计更新不会改变已发布策略。

时间语义、阈值、检测调用频率、路由排序规则及策略重播间隔不变。完整历史排序仍只在策略变化时执行。过期维护成本由每条样本承担一次；有批量过期时，单次判断仍可能处理多个过期样本，并非所有情况都保证固定耗时。

该结果证明控制判断的重复扫描和分配已减少，不能推算整机 TPS 的同比改善；完整 sidecar 验证、批次编码和持久化等更重路径未在本次改动中优化。
